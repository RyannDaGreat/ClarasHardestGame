# Limits

- Linux32 Mesa context measurement is concrete; historical Windows driver pixel-format selection remains unknown. A requested zero-bit buffer does not universally prove a selected zero-bit buffer.
- Hook drains GLerrors and writes an accumulation LOAD at firstswap. It preserves drawingbuffer pixels but is diagnostic instrumentation, not an untouched capture.
- No game-originated glAccum calls observed in45second Lv10 run; do not conclude those actuators never activate.
- No accumulation-buffer implementation is promoted. Validated isolated floatprototype was withheld because enabling it would change measured native behavior.
